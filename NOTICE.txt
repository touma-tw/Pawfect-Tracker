  MODIFICATIONS FROM THE PARENT FORK:
    - Repurposed the third offset family in the Device Offsets
      page from "Driver Offsets" (raw driver-space XYZ) to
      "DriverFromHMD Translation Offsets". Input is now
      interpreted in the HMD's yaw frame (right / up /
      forward relative to the user's facing direction),
      then frozen into the tracker's local space at the
      moment of input. The frozen offset behaves as a
      rigid body attachment: tracker translation/rotation
      carries the offset with it, but HMD movement does not
      affect the result. UI labels for the three axes have
      been changed from "X / Y / Z" to "左右 / 上下 / 前後"
      (left-right / up-down / forward-back).
    - Added one-click save and load of all tracker offset
      configurations as named presets.
    - Added Pause Offsets feature for T-Pose calibration
      workflows in VRChat.
    - Added Offsets Quick Menu page: view and adjust every
      tracker's offsets on a single screen, sorted by
      device role.
    - Device list now displays device roles (Waist, Foot,
      Left Knee, etc.) instead of raw serial numbers, using
      newer OpenVR APIs.

  親フォークからの変更点:
    - Device Offsets ページの三番目のオフセット項目を、従来の
      「Driver Offsets」(ドライバ空間の生 XYZ) から
      「DriverFromHMD Translation Offsets」に変更。入力値は
      HMD のヨー (水平方向の向き) を基準に「右 / 上 / 前」と
      して解釈され、入力した瞬間にトラッカーのローカル
      座標系に固定されます。これによりオフセットは
      トラッカーへの剛体取り付けのように動作し、トラッカー
      自身の移動・回転にはオフセットが追従しますが、HMD の
      動きはオフセットに影響しません。三軸の UI ラベルは
      「X / Y / Z」から「左右 / 上下 / 前後」に変更されています。
    - 全トラッカーのオフセット設定を名前付きプリセットとして
      ワンクリックで保存・読み込みする機能を追加。
    - VRChat の T-Pose キャリブレーション作業のための
      一時オフセット無効化機能 (Pause Offsets) を追加。
    - Offsets Quick Menu ページを追加: 全トラッカーのオフセットを
      デバイス役割順に並べて一画面で確認・調整できます。
    - デバイスリストでシリアル番号 (LHR-xxxx) の代わりに
      役割名 (Waist, Foot, Left Knee など) を表示するよう改善。
